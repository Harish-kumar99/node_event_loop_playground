This is a teaching simulator for the supported subset, not a full JavaScript engine. It models CommonJS-style top-level scheduling. Top-level setTimeout(0) vs setImmediate ordering can vary in real Node.js; this simulator displays timers before immediates for a repeatable walkthrough. Real I/O, async/await, variables, loops, imports, and arbitrary JavaScript are not simulated.
